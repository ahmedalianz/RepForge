# Schema conventions

The executable schema lives in numbered migrations, not a second schema definition.
Append migrations; never edit a shipped migration. `PRAGMA user_version` is advanced
inside the same transaction as its DDL. Failed upgrades roll back and show a retryable
startup error; the app never resets or deletes a database automatically.

IDs are local UUIDs generated by SQLite. Timestamps are UTC Unix milliseconds.
All weight columns are kilograms. Assisted weight is assistance, never a negative
external load. Bodyweight has NULL weight until a future body-mass model is designed.
Secondary muscles and routine exercise ordering use normalized relationship tables.
One active workout is enforced by a partial unique index. Persist each completed set
immediately; app lifecycle callbacks are not reliable persistence boundaries.
